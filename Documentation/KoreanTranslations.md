# 한국어 번역 전체 목록

설정에서 한국어 / English 전환 가능. 닉네임·방 코드·키보드 문자·등급 S/A/B/C/D·URL·고유 제작자 표기는 번역하지 않습니다. 숫자 자리표시자 {0} 등은 실제 값으로 표시됩니다.

구현 범위: 메인 메뉴, 일시정지, 대기실, 설정, 키 설정, 저장 목록/상태, 조작 안내, 튜토리얼, 돌 체력/재장전 표시, 타이머, 클리어 결과. 크레딧 화면과 크레딧 진입 버튼은 언어 설정에 관계없이 원문을 유지합니다. 인벤토리는 기존 이미지 방식을 유지하며 FIST/주먹과 HANDGUN/권총은 공용 아이템명 번역으로 등록했습니다.

첫 실행의 기본 언어는 운영체제 언어와 관계없이 영어입니다. 한국어는 설정에서 직접 선택할 수 있습니다. 선택한 언어는 기기에 저장되고 다른 플레이어의 설정에 영향을 주지 않습니다.

확인: Unity 배치 컴파일 및 Addressables 생성 성공. 151개 키 × 2개 언어 = 302개 값. 크레딧 14개 문구는 번역하지 않고 원문을 유지합니다. 한국어 번역 글리프 누락 0개. 실제 플레이 화면의 배치와 언어 전환 조작은 플레이 모드에서 확인하지 않았습니다.

## 크레딧 — 번역 제외

크레딧 화면의 제목(CREDITS), 안내, 출처 버튼(SOURCE), 뒤로 버튼(BACK), 제작자·에셋·음악·작품명과 링크는 모두 영어 원문을 유지합니다. 메인 메뉴와 클리어 화면의 CREDITS 버튼도 원문을 유지합니다.
