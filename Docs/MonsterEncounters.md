# 돌을 추적하는 몬스터

## 현재 동작

- `BoulderHunter.prefab`은 에셋의 Enemy A와 Idle / Walk / Attack / Die 애니메이션을 사용한다.
- 호스트만 NavMesh 추적, 명중 판정, 공격, 스폰, 사망을 처리한다. 참가자에게 위치와 상태가 동기화된다.
- 공격 대상은 돌뿐이다. 기본 공격 피해는 1, 공격 간격은 1.8초, 공격 준비는 0.45초다. 실제 타격 시에도 거리와 시야를 다시 확인한다.
- 몬스터 체력은 1인 7, 2인 9, 3인 11, 4인 13이다. 인원이 늘면 이미 받은 피해를 유지하면서 최대/남은 체력을 2씩 올린다. 권총의 `IDamageable` 피해 처리와 중앙 명중 표시를 그대로 사용한다.
- 돌 체력은 5이며 몬스터 공격으로만 감소한다. 권총·발차기로는 돌 체력이 줄지 않는다.
- 돌 체력이 0이면 1초 뒤 현재 체크포인트로 돌을 복귀시키고 체력 5로 회복한다. 남아 있는 몬스터를 제거하고 스폰 구역을 다시 준비한다.
- 돌이 장외 구역에 떨어져 복귀할 때도 체력을 5로 회복하고 남아 있는 몬스터와 스폰 구역을 초기화한다. 플레이어만 떨어졌을 때는 초기화하지 않는다.
- 돌 체력, 활성화된 구역, 살아 있는 몬스터의 위치·체력, 남은 생성 수량을 저장/이어하기에 포함한다.

## 스폰 구역 배치

Stage1에는 첫 번째 턴의 노란 표시 위치에 `Stage1MonsterTrigger`를 배치했다. 돌의 중심이 통과선을 넘으면 `Turn_02` 바깥쪽의 새 `MonsterSpawnPlatform`에서 한 마리가 생성된다. 몬스터 사망만으로 구역은 다시 준비되지 않으며, 돌이 장외로 떨어져 복귀한 뒤 다시 통과해야 재생성된다. 경사로 접합부의 작은 틈에는 지상 이동을 연결하는 NavMeshLink 두 개가 있다.

다른 구역을 추가할 때:

1. `Assets/Prefabs/MonsterSpawnZone.prefab`을 Stage1에 배치한다.
2. 루트의 Box Collider를 돌이 통과할 구간에 맞춘다. Is Trigger를 유지한다.
3. 자식 `SpawnPoint_01`을 몬스터가 나올 길바닥 위치로 옮긴다. 트리거와 생성 위치는 별개다.
4. `Entries`에서 생성 위치, 몬스터 프리팹, 수량, 생성 간격을 정한다. 여러 위치를 쓸 때는 Entries에 항목을 추가한다.
5. 이어하기의 구역 식별자를 고정하려면 `Encounter Id`에 구역마다 다른 이름을 넣는다. 비우면 씬 계층 경로를 사용한다.

한 구역은 한 시도에서 한 번만 발생하며, 플레이어가 지나가는 것으로는 발생하지 않는다. 지정 위치에서 가까운 NavMesh를 찾지 못하면 해당 생성은 건너뛰고 Console에 구역 이름을 남긴다. 임의 위치로 멀리 이동해 생성하지 않는다.

## 2스테이지 고정 포격 적

`Stage2ArtilleryTrigger`는 나선길 초반의 표시 구간을 돌 중심이 통과하면 지정 발판 `SpiralSummit (1)`에 `BoulderArtillery` 한 마리를 생성한다. Enemy C 모델과 애니메이션을 사용하며 위치를 이동하지 않고 돌 방향으로 회전만 한다.

발사 간격은 3초, 포탄 피해는 1이다. Missile 모델의 포탄은 발사 시 계산한 포물선을 따라 날아가며 유도되지 않는다. 호스트가 연속 구간 충돌 검사를 처리한다. 플레이어에게 피해를 주지 않으며 구조물에 막힌다. 원거리 적 체력·피격 표시·저장된 적 복원·스테이지 도달 시 사망은 근접 몬스터와 공유한다. 돌 복귀 또는 스테이지 완료 시 남아 있는 포탄도 제거한다.

## 코스를 수정했을 때

`Tools > Monsters > Rebuild Course Navigation`으로 이동 경로를 다시 굽는다. 기존 도로와 흙바닥만 포함하고 배경 산맥은 포함하지 않는다. 현재 에이전트는 지상 이동만 하며 틈을 뛰어넘지는 않는다.

## 주요 파일

- `Assets/CS/BoulderMonster.cs`: 추적, 근접 공격, 피해, 애니메이션 상태, 사망.
- `Assets/CS/BoulderHealth.cs`: 몬스터 전용 돌 피해와 체크포인트 복귀.
- `Assets/CS/MonsterSpawnZone.cs`: 돌 진입 스폰, 구역별 생성 목록과 저장 상태.
- `Assets/Editor/MonsterSetupEditor.cs`: 프리팹, 네트워크 등록, NavMesh 설치/재생성.
